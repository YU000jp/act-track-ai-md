# ActTrack AI

A personal desktop productivity tracker for Windows, built with Electrobun (Bun + Zig + WebView).

## Features

- **Window Tracking**: Monitors active windows via FFI (user32.dll)
- **AI Classification**: Google Gemini classifies activities as productive/distraction/neutral
- **Cache-First**: Classifications are cached locally - after a few days, 95%+ lookups are instant
- **Smart Notifications**: Native OS notifications when distracted, with grace period and cooldown
- **Dashboard**: Today view, statistics, and settings in a WebView panel
- **Daily AI Summary**: Automatic daily productivity summary generated by Gemini

## Requirements

- Windows 10/11 (x64)
- Microsoft Edge WebView2 Runtime
- Google Gemini API Key (free at https://aistudio.google.com/apikey)

## Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   bun install
   ```
3. Copy `.env.example` to `.env` and add your Gemini API key:
   ```bash
   cp .env.example .env
   ```
4. Run in development:
   ```bash
   bun --hot src/bun/index.ts
   ```

## Testing

```bash
bun test
```

## Building

```bash
bunx electrobun build --targets=win-x64
```

## Architecture

- `src/bun/` - Main process (tracker, classifier, notifier, summarizer, orchestration)
- `src/views/` - Dashboard UI (vanilla HTML/CSS/TS)
- `src/shared/` - Shared types and RPC contracts
- `data/` - Runtime SQLite databases (gitignored)

## Tech Stack

- **Electrobun** - Desktop framework (Bun + Zig + WebView)
- **Bun** - Runtime with FFI, SQLite, and fast startup
- **Google Gemini 2.0 Flash** - AI classification and summarization
- **SQLite** - Local data storage (WAL mode)
